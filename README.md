# パッケージメーカー

画像を入れると、500mlの紙パック飲料のパッケージになるWebページです。
サーバーやインストールは不要で、`index.html` を1つ開くだけで動きます。

## できること

- 画像(写真・イラスト)をパックの正面に貼る。形は「そのまま・角まる・まる・ハート」から選べます
- 商品名とひとことを入れる。太くて丸いフォントを選べます
- ステッカーを貼る(ハート・星・リボン・動物・果物など28種類と、自分の画像)。ドラッグで動かし、大きさとかたむきを変えられます
- パックの色と柄(ドット・ストライプ・ギンガム)を変える
- パックの横の面に、成分表とバーコードを入れる
- PNG または JPG で保存する(PNGは背景を透明にもできます)

## 使い方

`index.html` をダブルクリックして、ブラウザ(Chrome・Safariなど)で開きます。
下のメニューのタブ(画像・文字・色・ステッカー・横の面・保存)から操作します。

※ 作ったものは、ページを開き直すと消えます。必ず「保存」で画像にしてください。
※ フォントはインターネットから読み込みます。オフラインだと、書体が普通のゴシックに変わります。

## GitHubで公開する手順(GitHub Pages)

GitHub Pages を使うと、URLを知っている人が誰でもブラウザで使えるようになります。

1. GitHubで新しいリポジトリを作る(名前は例えば `package-maker`)
2. 「Add file」→「Upload files」で、`index.html` と `README.md` をアップロードして「Commit changes」
3. リポジトリの「Settings」→「Pages」を開く
4. 「Build and deployment」の「Source」を「Deploy from a branch」にする
5. 「Branch」を `main`、フォルダを `/ (root)` にして「Save」
6. 1〜2分待つと、`https://(あなたのユーザー名).github.io/package-maker/` で公開されます

非公開のリポジトリでGitHub Pagesを使えるかどうかは、プランによって違います。

## 注意

- バーコードは飾り用です。実際の商品の読み取りには使えません。
- 中に含まれているステッカー画像とパックの写真は、公開する前に、使ってよい素材か確認してください。公開や配布をする場合は、リポジトリに `LICENSE`(利用条件)も入れておくと安心です。
- フォントは Google Fonts(Mochiy Pop One、M PLUS Rounded 1c、Hachi Maru Pop、Dela Gothic One、Zen Maru Gothic)を読み込んでいます。各フォントの利用条件は Google Fonts のページで確認できます。
